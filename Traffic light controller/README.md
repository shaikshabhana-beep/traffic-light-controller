# Traffic Light Controller

## Description

A simple Verilog-based Traffic Light Controller designed using a Finite State Machine (FSM). It controls Red, Green, and Yellow traffic signals in a fixed sequence.

## Features

* Designed using Verilog HDL
* FSM-based design
* Controls Red, Yellow, and Green lights
* Simple and easy to simulate
* Includes a testbench for verification

## Traffic Sequence

The traffic lights operate in the following sequence:

**Red → Green → Yellow → Red**

## Files

* `traffic_light_controller.v` – Main Verilog design
* `traffic_light_controller_tb.v` – Testbench for simulation
* `expected_output.txt` – Expected simulation output

## Tools

This project can be simulated using:

* Icarus Verilog
* ModelSim
* Vivado

## Applications

* Traffic signal systems
* Digital electronics projects
* FPGA-based traffic controllers
* FSM learning projects
